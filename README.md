# Manual Reframe

Página de vendas do ebook **Manual Reframe: para entender qualquer pintura**,
do canal [ReFrame](https://www.youtube.com/channel/UC-3fWnVNx4a_gX6s2c97kBA).

A página é um arquivo único e autocontido: todas as imagens estão embutidas em
base64, não há CSS externo, fonte remota nem JavaScript de terceiros. Abre
direto do disco e não faz nenhuma requisição externa.

- `index.html` — a página inteira (~2,9 MB)

## Publicação

Serve como site estático em qualquer lugar. No GitHub Pages: Settings > Pages >
Source: branch `main`, pasta `/ (root)`.

## Imagens

Todas as obras reproduzidas estão em domínio público, obtidas no Wikimedia
Commons sob marcação PD-Art. A auditoria completa de direitos (27 obras, fonte,
licença e crédito de cada uma) está no repositório do produto.
